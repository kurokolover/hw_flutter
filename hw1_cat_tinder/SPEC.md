# Кототиндер · спецификация
Android-приложение с двумя вкладками. Принимаем результат по сценариям ниже.

- Карточка показывает фото и породу из одной записи TheCatAPI. Тап открывает это же фото и сведения о породе. После Back карточка и число лайков прежние.
- Вправо и кнопка сердца ставят лайк, влево и кнопка пропуска пропускают. Пока идёт смена карточки, повторный ввод игнорируется. Повтор загрузки после ошибки сохраняет уже начисленный лайк.
- Каталог открывает описание и 3–4 характеристики выбранной породы. Загруженный каталог сохраняется при переключении вкладок.
- Нет сети, ключа или данных, HTTP-ошибка, ответ без породы, таймаут и ошибка фото имеют понятное состояние с повтором. Уход с экрана во время запроса безопасен.
- Ключ и базовый URL передаются через dart-define. Сеть и типизированные модели отделены от интерфейса. Обязательные Semantics идентифицируют элементы для проверки. Своя иконка, читаемый узкий экран. В объём входят только сценарии задания.

## Проверки до сдачи
1. Прогнать dart format и flutter analyze с flutter_lints.
2. Проверить действия кнопками и свайпами, быстрый повтор, детали и Back, каталог, ошибки и восстановление, узкий экран. Осмотреть экраны.
3. Собрать release APK, проверить свежую установку, работоспособность и конфигурацию без ключа.
4. В журнале указать ревизии и реальные результаты, записать находки ревью. Сверить README, медиа, SHA и тег релиза.
